**00:39–00:59. Sign flip in the P₁/P₂ equations.** David: the final response-field equations "seem to be sign flipped". Claude redid the Euler–Lagrange variation and found **every term** of `eq:inst-rphi`/`eq:inst-rpi` had the wrong sign *and* a term was missing: because `μ = e^{−3Δs y/2}` depends on N explicitly, there is a measure-friction term `−μ̇/μ X = +(3/2)Δ̇s y X`. Cross-check: in the 1D limit the corrected equations reproduce `FullInstanton.bwd_rhs` exactly. The new term cancels the y-dependence of the advective-adjoint bracket, leaving the scalar `c(N) = (1−ε_core)(1/Δs − 3/2)`. The "Status of this derivation" caution panel was replaced by a calculation panel. *Recorded*: tex (calculation panel ~l.1106, corrected `eq:colloc-eqs` with note ~l.1612); implementation review §3 confirms the code implements `c(N)` identically at every node.

**00:58–01:04. Local Δs identity.** Claude Code had noticed the gradient prefactor `1/(r_out² (aH)_loc²)` equals `e^{−2Δs_loc}` with `Δs_loc` the same functional form as `Δs` but with local H.
